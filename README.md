# Galaxy Explorer - Advanced Responsive Website

## Project Overview

Galaxy Explorer is a modern, responsive, and interactive space tourism website built using HTML, CSS, and JavaScript. The project demonstrates front-end web development concepts such as responsive design, DOM manipulation, API integration, form validation, image sliders, and theme switching.

The website provides information about futuristic space travel services, including moon tours, space hotels, and astronaut-guided experiences.

---

## Features

### Responsive Design

* Mobile-friendly layout using CSS Media Queries
* Flexible layouts using CSS Flexbox
* Optimized for desktop, tablet, and mobile devices

### Hamburger Navigation Menu

* Mobile navigation menu
* Toggle functionality using JavaScript
* Improved user experience on small screens

### Dark / Light Mode Toggle

* Switch between dark and light themes
* Dynamic theme updates using JavaScript
* Enhanced accessibility and user preference support

### Image Slider

* Automatic slideshow of space-themed images
* Smooth image transitions
* Dynamic content presentation

### Contact Form with Validation

* User-friendly contact form
* JavaScript-based validation
* Prevents submission of empty fields
* Provides instant feedback to users

### SpaceX API Integration

* Fetches latest launch information from the public SpaceX API
* Displays real-time data dynamically
* Demonstrates asynchronous JavaScript and API consumption

## How to Run

1. Download all project files.
2. Place the files in the same folder.
3. Open `index.html` in any modern web browser.
4. Explore the website features:

   * Toggle dark/light mode
   * View image slider
   * Test responsive navigation
   * Submit the contact form
   * View SpaceX launch information

---

## Deployment

The project can be deployed using GitHub Pages:

1. Create a GitHub repository.
2. Upload all project files.
3. Go to Repository Settings.
4. Open Pages settings.
5. Select:

   * Source: Deploy from a branch
   * Branch: main
   * Folder: / (root)
6. Save changes.
7. Access the generated live website URL.
